EventForge

A game-agnostic event/story engine for building branching, interactive-fiction scenarios — with a visual graph editor and a full REST API, on top of Spring Boot and PostgreSQL.

Java · Spring Boot · Thymeleaf · PostgreSQL
About

EventForge lets you author events, conditions, player choices and weighted random transitions without touching code, then play them through the browser or drive them entirely over REST. The engine itself has zero dependency on Spring or JPA, so it could be reused as a standalone library.

Technologies
Java Spring Boot Thymeleaf PostgreSQL Maven Git

PocketTable

A local multiplayer platform for tabletop games, played over Wi-Fi with no internet connection or backend server required — one device hosts, others join with a room code.

Java · Android · Java-WebSocket
About

One device runs a local WebSocket server and acts as the authoritative host, while other players discover the room via UDP broadcast and join with a room code — no internet connection or external backend involved at any point.

Games
  • Poker — Texas Hold'em, side pots, hand evaluation
  • Color Clash
  • Mafia — configurable roles, day/night phases, voting
  • Makao, War, Blackjack — planned
Java Android Java-WebSocket Gson JUnit

QuestRoll

An offline-first D&D 5e companion app for Android — an SRD knowledge base synced from the Open5e API, a full character creator and sheet, campaign/session tracking, and fully custom, locally-authored content.

Java · Android · Room (SQLite) · Retrofit
About

On first launch, you pick which Open5e categories to sync locally into SQLite via Room. From there QuestRoll doubles as an encyclopedia, a multi-step character wizard with leveling, and a campaign tracker — all running fully offline, with house-rule content living alongside the official SRD data.

Current focus
  • Character creator & level-up wizard
  • Campaign sessions & notes
  • Custom classes, creatures, items, spells
  • Open5e sync & local SQLite cache
Java Android Room / SQLite Retrofit Gson
